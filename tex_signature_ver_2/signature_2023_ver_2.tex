	\section{Supervised learning with fractional Brownian motion and rough Bergomi volatility process}
	\subsection{Implementation details}\label{sec1}
	In the following numerical experiments, we will introduce various neural network models to calibrate parameters from time series data generated by fractional Brownian motions and rough Bergomi volatility processes.
	\subsubsection{Models' architecture}
	We first clarify the architecture of these neural network models that we will use in the following numerical experiments.
	
	The DeepSigNet model is a neural network model with signature transform proposed by \cite{Lyons_2019_DeepSignature}. The CNN model is a convolutional neural network proposed by \cite{stone_2020}. And we also provide another maxpooling CNN model and signature CNN model to explore whether the signature transform is a better choice than the maxpooling layer. The specific structures of these models are presented below:
	\begin{itemize}
		\item The DeepSigNet model:
		\begin{itemize}
			\item[-]a convolutional layer with 3 channels and kernel size 3;
			\item[-]augmented with time and original values;
			\item[-]the signature transform with truncation order $N=3$;
			\item[-]a fully connected feedforward neural network with 5 hidden layers, each of size 32 and ReLU activation;
			\item[-]the non-linear transform with sigmoid function.
		\end{itemize}
		\item The CNN model:
		\begin{itemize}
			\item[-]a convolutional layer with 32 channels and kernel size 20;
			\item[-]the leaky ReLu transform with negative slope 0.1;
			\item[-]a max pooling layer with size 3;
			\item[-]a dropout layer with rate 0.25;			
			\item[-]a convolutional layer with 64 channels and kernel size 20;
			\item[-]the leaky ReLu transform with negative slope 0.3;
			\item[-]a max pooling layer with size 3;
			\item[-]a dropout layer with rate 0.25;
			\item[-]a convolutional layer with 128 channels and kernel size 20;
			\item[-]the leaky ReLu transform with negative slope 0.1;
			\item[-]a max pooling layer with size 3;
			\item[-]a dropout layer with rate 0.4;
			\item[-]a dense layer with 128 units;
			\item[-]the leaky ReLu transform with negative slope 0.1;
			\item[-]a dropout layer with rate 0.3;
			\item[-]a dense layer with 1 units;
			\item[-]the non-linear transform with sigmoid function.			
		\end{itemize}
		\item The maxpooling CNN model:
		\begin{itemize}
			\item[-]a convolutional layer with 32 channels and kernel size 20;
			\item[-]the leaky ReLu transform with negative slope 0.1;
			\item[-]a max pooling layer with size 3;
			\item[-]a dropout layer with rate 0.25;
			\item[-]a dense layer with 128 units;
			\item[-]the leaky ReLu transform with negative slope 0.1;
			\item[-]a dropout layer with rate 0.25;
			\item[-]a dense layer with 1 units;	
			\item[-]the non-linear transform with sigmoid function.
		\end{itemize}
		\item The signature CNN model:
		\begin{itemize}
			\item[-]a convolutional layer with 32 channels and kernel size 20;
			\item[-]the leaky ReLu transform with negative slope 0.1;
			\item[-]the signature transform with truncation order $N=2$;
			\item[-]a dropout layer with rate 0.25;
			\item[-]a dense layer with 128 units;
			\item[-]the leaky ReLu transform with negative slope 0.1;
			\item[-]a dropout layer with rate 0.25;
			\item[-]a dense layer with 1 units;
			\item[-]the non-linear transform with sigmoid function.	
		\end{itemize}
	\end{itemize}
	\subsubsection{Simulated data set}
	We use simulated sample paths of fractional Brownian motions (fBm) $\{Z_t\}$ and rough Bergomi (rBergomi) volatility processes $\{V_t\}$ as the input data. 
	The fractional Brownian motion is defined as 
	\begin{equation}
		Z_t = \int_{0}^{t} (t-s)^{H-\frac{1}{2}} dW_s,\quad t>0,
	\end{equation}
	where $H\in(0,1)$ is the Hurst parameter and $W$ is a standard Brownian motion.
	The rBergomi volatility process is defined as
	\begin{equation}
		V_t = V_0 \exp \left(\eta\sqrt{2H}Z_t - \frac{\eta^2}{2} t^{2H}\right),\quad V_0>0,
	\end{equation}
	where $\eta$ is a strictly positive constant.
	
	To simulate these sample paths we use Cholesky decomposition; this very well-known simulation technique is recommended because the resulting sample paths have the exact distribution, rather than an approximate distribution, of the normalised log volatility process of the rBergomi model.

	\section{Calibration with signature transformer models}\label{sec2}
	\subsection{Signature $\&$ Transformer}
	Given a path $X=\{x_t | x_t=(x_t^1,\ldots,x_t^d)\in\mathbb{R}^d,\,t\in[a,b]\}$ with $a,\,b\in\mathbb{R}$ and $d\in\mathbb{N}^+$, we can define its signature by iterated integrals as follows
	\begin{eqnarray}\label{eq-signature}
		\text{Sig}(X)
		&=&\left(\underset{a<t_1<\cdots<t_k<b}{\int\cdots\int}dx_{t_1}\otimes\cdots\otimes dx_{t_k}\right)_{k\geq1}\nonumber\\
		&=&\left(\left(\underset{a<t_1<\cdots<t_k<b}{\int\cdots\int}dx_{t_1}^{d_1}\otimes\cdots\otimes dx_{t_k}^{d_k}\right)_{1\leq d_1,\ldots d_k\leq d}\right)_{k\geq1},
	\end{eqnarray}
	where $\otimes$ denotes the tensor product. From equation above, we can easily find that the $i\text{-th}$ signature of path $X$ is $\underset{a<t_1<\cdots<t_i<b}{\int\cdots\int}dx_{t_1}\otimes\cdots\otimes dx_{t_i},\,i=1,\,2,\,\ldots$ and we can also define the corresponding truncated signature as
	\begin{equation}
		\text{Sig}^N(X)=\left(\underset{a<t_1<\cdots<t_k<b}{\int\cdots\int}dx_{t_1}\otimes\cdots\otimes dx_{t_k}\right)_{1\leq k\leq N},
	\end{equation}
	with the truncation order $N$.
	
	Transformer is first proposed by \cite{vaswani_2017}. The key component in transformer is self-attention mechanism. To clarify this, we discretize the path $X$ with $n\in\mathbb{N}^+$ time grids as $X^n=(x_{t_1},\,\ldots,\,x_{t_n})\in\mathbb{R}^{n\times d},\,a=t_1<\cdots<t_n=b$. Let $W_Q\in\mathbb{R}^{d_{\text{attn}\times d}},\,W_K\in\mathbb{R}^{d_{\text{attn}\times d}}$ and $W_V\in\mathbb{R}^{d_{\text{attn}\times d}}$ with $d_{\text{attn}}\in\mathbb{N}^+$, then we can define the query, key and value in self-attention mechanism as $Q=X^nW_Q^T,\, K=X^nW_K^T$ and $V=X^nW_V^T$, respectively, which are linear projections from the path. Then the self-attention can be defined as
	\begin{equation}
		\label{eq-self-attention}
		\text{Self-Attention}(X^n;\,W_Q,\,W_K,\,W_V):=\text{softmax}\left(\frac{QK^T}{\sqrt{d}}\right)V.
	\end{equation}
	Intuitively, self-attention can be viewed as the combination of linear and non-linear transformation applied to the input $X^n$ which is similar to the multilayer perceptron (MLP).
	
	If we compare signature transform with self-attention mechanism, there is only one specific $\text{Sig}(X^n)$ corresponding to the path $X^n$ while there are countless $\text{Self-Attention}(X^n;\,W_Q,\,W_K,\,W_V)$ with different weight matrix $W_Q,\,W_K$ and $W_V$. The transformer, including the self-attention mechanism, is a typical neural network that can be trained while signature transform is a feature map that transforms paths into fixed-dimensional vectors capturing important statistical information.

	To combine signature transform with transformer, we need to preserve the stream-like nature of input data because signature transform will consume it. To illustrate this, we compare the dimension of input path $X^n\in\mathbb{R}^{n\times d}$ and output $\text{Sig}^N(X^n)\in\mathbb{R}^{\frac{d^{N+1}-1}{d-1}-1}$, there is no underlying path in $\text{Sig}^N(X^n)$ i.e. without stream-like nature. The solution is to lift the input data as
	\begin{eqnarray}
		\label{eq-lift}
		l(X^n)
		&=&(l_2(X^n),\,l_3(X^n),\,\ldots,\,l_n(X^n))\nonumber\\
		&=&((x_{t_1},\,x_{t_2}),\,(x_{t_1},\,x_{t_2},\,x_{t_3}),\,\ldots,\,(x_{t_1},\,\ldots,\,x_{t_n})),
	\end{eqnarray}
	where $l_i(X^n):=(x_{t_1},\,\ldots,\,x_{t_i}),\,i=2,\,3,\,\ldots,\,n$. Then the output becomes to $\text{Sig}^N(l(X^n))\in\mathbb{R}^{(n-1)\times(\frac{d^{N+1}-1}{d-1}-1)}$.
	
	\subsection{Models' architecture}
	In this section, we clarify the architecture of three signature transformer models that we will use in the following numerical experiments.
	\begin{itemize}
		\item The $\text{SigFormer}\_1$ model:
		\begin{itemize}
			\item[-]a convolutional layer with 3 channels and kernel size 3;
			\item[-]augmented with time and original values;
			\item[-]lifted as equation~\eqref{eq-lift};
			\item[-]the signature transform with truncation order $N=3$;
			\item[-]the transformer layer with self-attention mechanism;
			\item[-]a fully connected feedforward neural network with 5 hidden layers, each of size 32 and ReLU activation;
			\item[-]the non-linear transform with sigmoid function.
		\end{itemize}
		\item The $\text{SigFormer}\_2$ model:
		\begin{itemize}
			\item[-]a convolutional layer with 3 channels and kernel size 3;
			\item[-]augmented with time and original values;
			\item[-]lifted as equation~\eqref{eq-lift};
			\item[-]the signature transform with truncation order $N=3$;
			\item[-]the transformer layer with self-attention mechanism;
			\item[-]a linear transform layer;
			\item[-]the non-linear transform with sigmoid function.		
		\end{itemize}
		\item The $\text{SigFormer}\_3$ model:
		\begin{itemize}
			\item[-]augmented with time;
			\item[-]the transformer layer with self-attention mechanism;
			\item[-]lifted as equation~\eqref{eq-lift};
			\item[-]the signature transform with truncation order $N=3$;
			\item[-]a fully connected feedforward neural network with 5 hidden layers, each of size 32 and ReLU activation;
			\item[-]the non-linear transform with sigmoid function.
		\end{itemize}
	\end{itemize}
	In addition to these three models, we also introduce My DeepSigNet and CNN model in Section~\ref{sec1} for comparison.
